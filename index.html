What is curl-load?

curl-load is a lightweight local workbench and dashboard for building and running curl-based load tests. It runs as a small self-hosted service (via Docker) that you point tools like the Curl Load Workspace Launcher Chrome extension at.

Curl Load Workspace Launcher (Chrome Extension)

A one-click shortcut that opens your curl-load Workbench and Dashboard together as a grouped tab set in Chrome, so you don't have to open and arrange them manually.

Requires a running curl-load instance (local or remote) — the extension does not include or host curl-load itself.

Run locally:

docker run -p 3000:3000 -p 5665:5665 -v curl-load-runs:/app/runs curlload/curl-load-runner:latest
