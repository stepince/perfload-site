PerfLoad MCP — Load Testing for AI Agents Coming soon

Your AI Agent. Your API. Real Performance Insights.

PerfLoad MCP is coming soon. It will let AI coding agents create, run, and analyze API load tests through the Model Context Protocol (MCP), using the same PerfLoad runner and k6 engine that powers PerfLoad today. This page describes planned functionality; it is not available yet and has no release date.

How PerfLoad MCP will work

PerfLoad MCP is planned as an MCP server that sits between your AI coding agent and your existing PerfLoad load-testing infrastructure. The agent talks MCP; PerfLoad does the load generation with k6 and returns the results.

  1. Your AI agent
  2. PerfLoad MCP (planned)
  3. PerfLoad runner + k6
  4. Metrics back to the agent
  1. Describe what you need. Tell an AI agent your performance testing requirements in plain language.
  2. The agent creates a test. It builds a PerfLoad test using MCP.
  3. PerfLoad runs it. The load test is executed with k6.
  4. The agent reads the metrics. Response times, throughput, and error rates come back through MCP.
  5. It analyzes the results. The agent reviews the numbers and flags potential performance regressions.

What you can do today

PerfLoad already turns a cURL command into a k6 load test from the Workbench, and its built-in skill files let AI browser tools such as Claude in Chrome drive the Workbench from a prompt. MCP is a separate, planned integration that is still under development.

FAQ

Is PerfLoad MCP available?

No. It is under development and labelled Coming Soon. There is no release date, and nothing to download or install yet.

Does it work with Claude Code or Cursor today?

No. Compatibility with MCP-enabled tools such as Claude Code and Cursor is planned, not shipped.

What is MCP?

The Model Context Protocol is an open standard that lets AI applications connect to external tools and data sources.

Will it use k6?

Yes. Load tests are planned to run on the same PerfLoad runner and k6 engine used today.
