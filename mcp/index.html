PerfLoad MCP New

Your AI Agent. Your API. Real Performance Insights. PerfLoad MCP lets AI coding agents create, run, and analyze API load tests through the Model Context Protocol (MCP), using the same PerfLoad runner and k6 engine that power PerfLoad today.

How it works

  1. Describe what you need. Tell an AI agent your performance testing requirements.
  2. The agent creates a test. It builds a PerfLoad test using MCP.
  3. PerfLoad runs it. The load test is executed with k6.
  4. The agent reads the metrics. Response times, throughput, and error rates come back through MCP.
  5. It analyzes the results. The agent reviews the numbers and flags potential performance regressions.

Example use case

Example prompt

“Run a load test against my API with 100 virtual users for 60 seconds. Report the p95 latency, throughput, and error rate.”

What it does

  • AI Agent Integration — works with MCP-enabled tools such as Claude Code and Cursor
  • Natural Language Testing — ask your AI agent to create and execute load tests
  • cURL to Load Test — convert existing API requests into performance tests
  • Performance Analysis — retrieve response times, throughput, error rates, and performance metrics
  • Regression Detection — compare test runs to identify potential performance regressions
  • Automated Workflows — integrate performance testing into AI-assisted development and CI/CD workflows

Turn it on

MCP is off by default. Set PERFLOAD_MCP_ENABLED=true and PerfLoad serves an MCP endpoint at /mcp (Streamable HTTP). It works in both single-user and Multiuser mode.

Single-user MCP

For a private machine or one person. No sign-in and no token.

docker run -d --name perfload \
  -p 3000:3000 \
  -v perfload-runs:/app/runs \
  -e PERFLOAD_MCP_ENABLED=true \
  perfload/perfload-runner:latest

Connect your agent with just the URL:

claude mcp add --transport http perfload http://localhost:3000/mcp

Cursor (.cursor/mcp.json): 

{ "mcpServers": { "perfload": { "url": "http://localhost:3000/mcp" } } }

Anyone who can reach the server can start load tests, so keep this to a machine only you can reach.

Multiuser MCP

For a team on a shared server. Each person signs in and connects with a personal token, and the agent only sees that person's tests and runs. 

docker run -d --name perfload \
  -p 3000:3000 \
  -v perfload-runs:/app/runs \
  -e PERFLOAD_AUTH_ENABLED=true \
  -e PERFLOAD_AUTH_PROVIDERS=local \
  -e PERFLOAD_ADMIN_EMAIL=you@example.com \
  -e PERFLOAD_MCP_ENABLED=true \
  perfload/perfload-runner:latest

Sign in (see Multiuser for the first-administrator setup), open Account & API keys and create a token. It is shown once. Then connect your agent with it: 

export PERFLOAD_TOKEN=pl_...
claude mcp add --transport http perfload https://YOUR_PERFLOAD_HOST/mcp \
  --header "Authorization: Bearer $PERFLOAD_TOKEN"

Cursor (.cursor/mcp.json): 

{ "mcpServers": { "perfload": {
  "url": "https://YOUR_PERFLOAD_HOST/mcp",
  "headers": { "Authorization": "Bearer ${env:PERFLOAD_TOKEN}" } } } }

Never commit tokens. Over a network, use HTTPS; plain HTTP is only accepted on localhost.

Then ask your agent to list your tests, or try the example prompt above.

Key settings

VariableMeaning
PERFLOAD_MCP_ENABLEDDefault false. Set true to turn MCP on.
PERFLOAD_MCP_MAX_VUSPer-run virtual user cap for runs started over MCP. Default 100.
PERFLOAD_MCP_MAX_DURATION_SECPer-run duration cap. Default 600.
PERFLOAD_MCP_RATE_LIMITRequests per minute per user. Default 120.
PERFLOAD_MCP_ALLOWED_TARGETSComma-separated hostnames allowed even if they resolve to private addresses.

FAQ

Is PerfLoad MCP available?

Yes. PerfLoad MCP has been released.

Does it work with Claude Code or Cursor?

It works with MCP-enabled tools such as Claude Code and Cursor.

What is MCP?

The Model Context Protocol is an open standard that lets AI applications connect to external tools and data sources.

Will it use k6?

Yes. Load tests run on the same PerfLoad runner and k6 engine used today.
