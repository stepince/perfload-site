PerfLoad MCP Coming soon

Your AI Agent. Your API. Real Performance Insights. PerfLoad MCP is being built to let AI coding agents create, run, and analyze API load tests through the Model Context Protocol (MCP), using the same PerfLoad runner and k6 engine that power PerfLoad today. This page describes planned functionality — it is not available yet and has no release date.

How it will work

  1. Describe what you need. Tell an AI agent your performance testing requirements.
  2. The agent creates a test. It builds a PerfLoad test using MCP.
  3. PerfLoad runs it. The load test is executed with k6.
  4. The agent reads the metrics. Response times, throughput, and error rates come back through MCP.
  5. It analyzes the results. The agent reviews the numbers and flags potential performance regressions.

What's coming

  • AI Agent Integration — planned compatibility with MCP-enabled tools such as Claude Code and Cursor
  • Natural Language Testing — ask your AI agent to create and execute load tests
  • cURL to Load Test — convert existing API requests into performance tests
  • Performance Analysis — retrieve response times, throughput, error rates, and performance metrics
  • Regression Detection — compare test runs to identify potential performance regressions
  • Automated Workflows — integrate performance testing into AI-assisted development and CI/CD workflows

What you can do today

PerfLoad already turns a cURL command into a k6 load test from the Workbench, and its built-in skill files let AI browser tools such as Claude in Chrome drive the Workbench from a prompt. MCP is a separate, planned integration that is still under development. See curl to k6, API load testing, and CI/CD load testing.

FAQ

Is PerfLoad MCP available?

No. It is under development and labelled Coming Soon. There is no release date, and nothing to download or install yet.

Does it work with Claude Code or Cursor today?

No. Compatibility with MCP-enabled tools such as Claude Code and Cursor is planned, not shipped.

What is MCP?

The Model Context Protocol is an open standard that lets AI applications connect to external tools and data sources.

Will it use k6?

Yes. Load tests are planned to run on the same PerfLoad runner and k6 engine used today.
