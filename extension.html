Curl Load Workspace Launcher

A Chrome extension that opens your curl-load Workbench and Dashboard together as a grouped tab set, one click from the toolbar.

What it does

  • Click the toolbar icon to open the Workbench and Dashboard together, grouped under a labeled "curl-load" tab group
  • Checks that both URLs are reachable first, so you're never left staring at broken tabs if your curl-load instance isn't running
  • Configurable Workbench and Runner Dashboard URLs — works against a local Docker instance or a remote deployment
  • Settings saved locally via chrome.storage.local and persist across browser restarts

Requirements

This extension requires a running curl-load instance (local or remote) — it does not include or host curl-load itself.

Run locally:

docker run -p 3000:3000 -v curl-load-runs:/app/runs curlload/curl-load-runner:latest

Permissions used

  • tabs — to open and group the Workbench/Dashboard tabs
  • tabGroups — to label the group "curl-load"
  • storage — to save your configured URLs locally
