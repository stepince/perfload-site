Curl Load Workspace Launcher

A Chrome extension that opens your curl-load Workbench, grouped under a "curl-load" tab group, one click from the toolbar.

Add to Chrome →

What it does

  • Click the toolbar icon to open (or refocus, if already open) the Workbench tab, placed in a labeled "curl-load" tab group
  • From there, use the Workbench's own "curl-load dashboard →" link to open the Dashboard — since that's a real click rather than something the extension does programmatically, Chrome properly links the two tabs, so later clicks on either page's link reliably reuse the same tab instead of opening duplicates
  • Checks that the Workbench URL is reachable first, so you're never left staring at a broken tab if your curl-load instance isn't running
  • Configurable Workbench URL — works against a local Docker instance or a remote deployment
  • Settings saved locally via chrome.storage.local and persist across browser restarts

Requirements

This extension requires a running curl-load instance (local or remote) — it does not include or host curl-load itself.

Run locally:

docker run -p 3000:3000 -v curl-load-runs:/app/runs curlload/curl-load-runner:latest

Permissions used

  • tabGroups — to label the group "curl-load"
  • storage — to save your configured Workbench URL locally
